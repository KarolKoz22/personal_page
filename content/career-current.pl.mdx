# Profil Zawodowy

Jestem **inżynierem Platform / DevOps** z około trzyletnim doświadczeniem w **Visa** i **Samsung Electronics**. Buduję automatyzację CI/CD, bramki jakości DevSecOps i skonteneryzowane środowiska deweloperskie, opierając się na solidnych podstawach Linuksa i inżynierii systemowej.

## Kompetencje

- **CI/CD i dostarczanie:** reużywalne workflow GitHub Actions, automatyczne testy i pokrycie kodu, wersjonowanie semantyczne, publikacja artefaktów (JFrog Artifactory)
- **DevSecOps:** skanowanie jakości kodu i podatności zintegrowane z pipeline'em (SonarQube, Checkmarx, Sonatype Nexus, Black Duck)
- **Kontenery i chmura:** Docker, Docker Compose, Docker Swarm, Kubernetes, AWS (EKS, IAM, VPC), Terraform, Ansible
- **Linux i systemy:** wnętrze jądra, embedded Linux i Yocto, hypervisory ARM, TrustZone/TEE, secure boot, systematyczna diagnostyka problemów

## Po Godzinach

Utrzymuję 3-węzłowy homelab Kubernetes zarządzany w modelu GitOps (Argo CD), który służy mi jako praktyczne laboratorium inżynierii platformowej. Więcej na stronie [Projekty](/projects).
